### the idea

I don't think of code as engineering so much as **leverage**. A computer can do a
boring thing ten million times without getting tired or bored or resentful about it.
That's the whole trick. Everything else — frameworks, patterns, the discourse — is
detail.

So the things I build tend to start the same way: something annoyed me twice, and
the second time I decided I wasn't going to do it a third.

### what I'm doing right now

- building my portfolio in **Next.js 16 / React 19 / Tailwind v4** (it is currently a very confident-looking blank page)
- automating the small repetitive parts of my day until there aren't any left
- learning by shipping badly first, then fixing it

## 🎮 the game

**Guess My Number.** I'm thinking of a number between 1 and 100.

You get 7 guesses. Click one — it opens an issue, a bot replies *higher* or *lower*,
and you go again. Beat it and your name goes on the board below.

<p align="center">
  <a href="https://github.com/RohanS358/RohanS358/issues/new?title=guess%3A%2050&body=I+guess+50.+%28Edit+the+number+in+the+title+to+guess+again.%29&labels=game"><img src="https://img.shields.io/badge/start%20with-50-4c1?style=for-the-badge" alt="Guess 50"></a>
</p>

<p align="center">
  <sub>after that, just edit the number in the issue title to keep guessing.<br>
  new secret number every week. no scripts run on this page — GitHub strips them —<br>
  so the board is kept honest by a GitHub Action.</sub>
</p>
